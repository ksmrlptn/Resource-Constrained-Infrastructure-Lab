## Overview
Out of aging and repurposed hardware, this personal project serves as an environment for hands-on application of Systems Administration, Systems Support, Networking, and Troubleshooting skills acquired through academic coursework and some personal experience.

## Objective
To develop operational capability through a documented infrastructure lifecycle. This repository documents the project's lifecyle, Technical Decisions, Incident Investigations, Recovery Procedures, and Operational Improvements as evidence of hands-on learning and applied Problem-Solving.

## Current Technologies
- Arch Linux
- OpenSSH
- Tailscale
- Glances

- Phase 2: System Building
- Phase 3: System Maintenance
- Phase 4: Troubleshooting
